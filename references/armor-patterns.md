# v2 审查协议

## 不再用禁词分数裁决回复

v1 的 hard/soft/style 和 90 分门槛已移除。v2 的输出有 `schema_version: 2`，`stats.score: null`。文件/标准输入、`--json` 和退出码角色保留；`--min-score` 明确报输入错误，不静默忽略。v1 的 `render` 与旧规则编号不再作为兼容 API；当前程序入口为 `audit(text, baseline=None, contract=None)`。

## 三类结果

| verdict | 含义 | CLI 退出码 |
|---|---|---|
| BLOCKED | 声明的必须保留项缺失，或命中禁用断言 | 1 |
| REVIEW | 有措辞/新数字提示，或没有提供信息合同 | 0 |
| CHECKED | 所提供合同和表层检查没有发现问题 | 0 |

输入错误退出 2。`passed` 只表示没有机器阻断，不表示事实正确；每份报告都带 `semantic_review_required: true`。

## 措辞线索：只提示，不自动删

| 规则 | 检查范围 | 人工判断 |
|---|---|---|
| A01 | AI 身份前置 | 是否真的在解释能力边界 |
| A02 | 通用免责 | 是否是用户要保留的原文或条款 |
| A03 | 赞美开场、结尾推销 | 是否提供了信息或真实情绪回应 |
| A04 | 正文首句的少数铺垫句式 | 是否应先给答案；不会匹配首句中间 |
| A05 | 少数绝对化断言 | 是否有足够证据，不自动判错误 |

不对单独的“可能”“建议”“抱歉”“不能”扣分。Markdown 围栏代码、行内代码、缩进代码、块引用和标题从措辞检查中屏蔽，原文坐标不移动。这里只是常用 Markdown 片段识别，不是完整 Markdown 解析器。

## 信息合同

先从用户请求和证据建立保留项，不能看候选答案后降低要求来凑通过。合同必须正好含三个顶层键；`required` 为 1 到 100 项，ID 唯一。每个 `any_of` 有 1 到 20 个非空字面片段，匹配任一个即为命中；不支持正则，也不执行其中的文本。

```json
{
  "schema_version": 2,
  "required": [
    {
      "id": "uncertainty",
      "kind": "uncertainty",
      "label": "不能把超时现象当根因",
      "source": "用户只提供超时日志，不能确定根因。",
      "any_of": ["不能确定根因", "尚未确定根因"]
    }
  ],
  "forbidden": ["根因就是数据库"]
}
```

`kind` 支持 fact、condition、uncertainty、boundary、output。`source` 记录来源摘要，不证明来源本身正确。对否定命题使用完整片段，而不是只写“根因”；替代表达要先人工确认语义，不能把“确定”和“不能确定”列为同义词。

- C01：声明锚点未命中，阻断，要求检查遗漏或同义改写。
- C02：声明禁止的字面断言出现，阻断，要求复核；引用中出现也会命中。
- C03：比基线和声明来源多出 ASCII 数字，提示核实，不自动断言编造。没有 `--baseline` 时明确显示未检查。

`offset`/`end` 是 Python Unicode 字符索引，左闭右开，不是 UTF-8 字节。缺失锚点没有位置，返回 null。数字扫描识别整数和小数的字面片段；不理解单位、数字顺序、中文数词和业务语义。相同数字换了单位也可能漏报，必须人工核对。

## 限制与对抗例

把所有锚点粘在脚注、用否定句反驳锚点、引用一句话再给相反结论，都可能机械命中而语义错误。不要把合同当自动发布授权。

工具不理解来源真实性、不生成改写、不核实是否真的执行了外部动作；不理解全部语言和修辞。复核必须对照请求、来源和候选全文。对原文错误先纠错，不以“保留原句”为目标。

## 资源与安全

仅用 Python 标准库，单个输入最大 1 MB；UTF-8/UTF-8 BOM 可读，非法编码、空输入、缺文件、非法合同和 JSON 错误显式返回 2。无网络、无 shell 执行、无自动回写，不自动留存用户草稿。

Skill 元数据遵循 https://agentskills.io/specification：name/description 为必需字段，metadata 是字符串到字符串的映射。`scripts/`、`references/`、`assets/` 是惯例而非排他白名单。`_meta.json` 仅保留本地分发描述，不承诺任何平台凭它自动加载。
